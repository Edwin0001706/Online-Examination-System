# Online Examination System

## Project Description
A simple web-based Online Examination System created for demonstrating Git and GitHub version control operations.

## Features
- Student login
- Java programming examination
- Multiple-choice questions
- Automatic result calculation
- Simple student examination interface

## Technologies
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Git Practical Requirements
1. Repository creation
2. Main and feature/login branches
3. Meaningful commits
4. Feature branch merge / Pull Request
5. Merge conflict and resolution
6. v1.0.0 tag
7. git log, git show, git diff, git blame
8. git bisect
